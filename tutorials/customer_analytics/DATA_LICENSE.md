Transformations: schema aliases normalized; invalid, cancellation and documented administrative lines
excluded; ambiguous invoices quarantined using only observations available at each snapshot; exact
qualifying lines deduplicated as an explicit benchmark convention; customer snapshots and deterministic
bounded cohorts derived. Duplicate provenance is unresolved. Positive line value is in original GBP,
not profit or settled revenue. Source timezone is unspecified; timestamps remain source-clock naive.

The source concerns a UK retailer and does not establish Philippine capture, small-business size,
marketing responsiveness or customer anonymity. Raw transaction logs are excluded from results bundles.
